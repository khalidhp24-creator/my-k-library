My K Library: Programmer's Coding Manual (V14 - Branding & Icons)

This manual covers V14, implementing custom application branding and Win32 icon resources.

1. Executable Branding (Win32 Icon)

The application icon (displayed in Explorer and the Desktop) is now permanently linked into the LibraryAppVB.exe executable using the /win32icon compiler directive during the build process.

vbc.exe ... /win32icon:bookic2.ico ...

2. Dynamic Icon Conversion

To ensure compatibility with the Visual Basic compiler, the original bookic2.png was programmatically downsampled and converted into a standard 32x32 Win32 Icon (.ico) format during the deployment cycle.

3. Internal UI Branding

A small branding logo (bookic1.png) is now dynamically loaded into the MainForm next to the navigation menu. This provides a consistent "branded" experience while navigating between libraries.

4. Taskbar & Title Bar Icons

The Me.Icon property of the MainForm is set at runtime. This ensures the application icon is visible in the Windows Taskbar and in the top-left corner of the title bar.
