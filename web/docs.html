My K Library Documentation

A complete guide to the cloud-native, multi-platform library management system. Runs seamlessly across desktop, web, and mobile devices.

Status: Cloud database active on Supabase & deployed globally on Vercel. 100% Free tier architecture ($0.00 / month).

1. System Architecture

My K Library operates on a modern hybrid architecture connecting three synchronized touchpoints to a central cloud PostgreSQL database:

  • Cloud PostgreSQL (Supabase): Managed PostgreSQL database (`my-k-library`, ref: kgvopwljwpeqkaindqbs) with automatic REST API, real-time WebSocket subscriptions, and Row Level Security.
  • Adaptive Web App (Vercel): Responsive web app (HTML5, Vanilla JS, CSS3) with automatic breakpoint adaptation for desktops (wide table grid) and smartphones (touch feed & camera scanner).
  • Desktop Application (VB.NET / WinForms): High-performance 32-bit Windows desktop client with offline Jet Access fallback and background HTTP server.

2. Quick Start

  1. Open the Web App: Visit the live URL on your desktop or mobile browser.
  2. Switch Libraries: Select between Default Library or custom collections from the top dropdown or sidebar.
  3. Instant Search: Type in the search box to filter in real-time across book title, author, or ISBN.
  4. Add a Book: Click + Add Book to manually enter details or use the 📷 Scan ISBN feature to auto-fill metadata.

4. ISBN Lookups & AI Cataloging

When cataloging books, you can enter or scan an ISBN to automatically pull complete bibliographic details:

🔍 Engine 1: Google Books API (with ISBNSearch fallback)

Queries Google's book repository to fetch the official Title, Author, Publisher, Publication Year, and High-Resolution Cover Art.

🤖 Engine 2: Google Gemini AI (Gemini 2.0 Flash)

Uses AI cataloging to analyze the ISBN and generate detailed metadata including Subject Tags, Page Count, Language, and a complete Synopsis / Summary.

5. Mobile Camera Barcode Scanner

The web app includes an integrated camera scanner using HTML5 camera streams:

  • Works natively in Safari (iOS), Chrome (Android/Windows), and Edge without installing app store packages.
  • Point your smartphone camera at a physical book's EAN-13 barcode.
  • An audible tone confirms detection, stops the camera, and immediately queries Google Books to fill out the catalog form.

5.1 Desktop Touch Screen Interface (Kiosks & Surface Tablets)

Designed specifically for desktop touch monitors, all-in-one PCs, and Windows Surface tablets:

  • One-Tap Mode Switch: Click or tap 🖐️ Touch UI in the top bar or sidebar to toggle between compact mouse mode and spacious touch mode.
  • Touch Kiosk Card Grid: Transforms dense spreadsheet table rows into large, interactive touch tiles with prominent cover previews and large tap buttons.
  • Enlarged Touch Targets: All buttons and input fields expand to 48px – 56px with generous spacing to eliminate accidental mis-taps.
  • Auto-Detection: Automatically activates touch mode if a touch-screen device is detected via hardware sensor query.
  • WinForms Native Support: The Windows desktop executable (LibraryAppVB.exe) also includes a matching 🖐️ Touch UI toggle in its sidebar that enlarges grid rows to 50px with 12pt fonts.

6. User Roles & Security Policy

My K Library enforces multi-tiered Role-Based Access Control (RBAC). In accordance with organizational security policies, credentials and sensitive user records are decoupled from public documentation.

Confidential Credentials Storage: All provisioned staff and reader credentials are saved securely in your project's local directory (credentials.csv and credentials.txt). To safeguard the system, passwords are never exposed on client login pages or public web documentation.

Defined Role Hierarchy

  • SuperAdmin (System Administrator): Complete administrative authority across all libraries, schema configurations, collection provisioning, and user role assignments.
  • Admin (Librarians): Comprehensive library operations, adding/editing books, managing book metadata, managing collections, and handling circulation desk workflows.
  • User / Cataloger: Catalog management permissions including barcode scanning, Google Books ISBN metadata fetching, and updating book status.
  • User / Reader & Guest: Read-only access to browse, search, filter catalogs, and launch online e-book readers without editing permissions.

Authentication & Security Architecture

User accounts are securely verified against the cloud PostgreSQL app_users table. Session states are managed with isolated local/session storage. Administrators may provision new accounts, update roles, or rotate passwords at any time via the database or desktop management suite.

7. Database Schema Reference

The Supabase PostgreSQL database consists of 5 relational tables:

-- 1. Libraries (Collections)
CREATE TABLE libraries (
    name TEXT PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Book Categories (369 Genres)
CREATE TABLE book_categories (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT UNIQUE NOT NULL
);

-- 3. Books Table
CREATE TABLE books (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    library_name TEXT REFERENCES libraries(name),
    title TEXT NOT NULL,
    author TEXT,
    author2 TEXT,
    pages INTEGER,
    pub_year INTEGER,
    publisher TEXT,
    isbn TEXT,
    copy_num INTEGER DEFAULT 1,
    series TEXT,
    cover_path TEXT,
    back_path TEXT,
    genre TEXT,
    description TEXT,
    language TEXT,
    subjects TEXT,
    category_id BIGINT REFERENCES book_categories(id),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Application Settings
CREATE TABLE app_settings (
    key_name TEXT PRIMARY KEY,
    setting_value TEXT
);

-- 5. Application Users
CREATE TABLE app_users (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    role TEXT NOT NULL DEFAULT 'User'
);

8. FAQs & Troubleshooting

Q: Can I add a shortcut to my smartphone home screen?

Yes! In Safari (iPhone), tap the Share button and choose Add to Home Screen. In Chrome (Android), tap the three dots menu and choose Install App or Add to Home screen. It will open like a standalone native app.

Q: What if camera scanning doesn't start on mobile?

Make sure you granted camera permissions to the browser. Under iOS Settings > Safari > Camera, ensure it is set to "Allow" or "Ask".

Q: Are changes on the web visible immediately in the desktop app?

Yes. Both connect to the same Supabase cloud database, meaning additions or edits made on your phone appear across all connected clients.
