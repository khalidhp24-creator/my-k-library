My K Library: Programmer's UI Coding Manual (V15 - Redesign)

This manual covers the UI Components Redesign for V15, including resolution scaling, modern components, and layout persistence.

1. Resolution Manager

The UI relies on resolutionMode stored in the Settings table (Small, Medium, Large). When initialized, ApplyResolutionSize() configures the main window dimensions, and scales the base font up/down dynamically. Buttons generated via CreateAutoBtn pull height logic and font scaling from this specific mode.

2. Dynamic FlowLayout Buttons

All toolbars (Header, Welcome Actions, Library Actions, Scan Row) have been upgraded to FlowLayoutPanel structures. Buttons configure AutoSize = True and specific Padding metrics so text never gets clipped regardless of language or screen width.

3. Z-Index and Docking Flow

The DataGridView bugs encountered during refactoring were deeply tied to WinForms internal Z-Index docking algorithms.

  • SendToBack() forces top-docked panels (like nav row) to secure vertical space first.
  • BringToFront() forces the core pnlGridArea and dgvBooks to evaluate last, allowing them to perfectly consume the remaining client screen space without hiding behind standard panels.

4. Visual Studio WinForms Designer

We introduced MSBuild `.vbproj` integration. For Visual Studio to load the designer accurately without splitting the Program.vb file into two, the Module Program has been relocated to the bottom of the file, allowing MainForm to act as the primary graphical type for designer tools.
